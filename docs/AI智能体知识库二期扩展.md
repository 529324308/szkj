# AI智能体知识库二期扩展

## 1. 二期目标

二期目标是在一期知识库系统稳定运行的基础上，扩展自然语言控制网页与地图页面的能力，把知识问答、网页控制、空间操作、模板生成和文档归档统一到一个入口中。

二期不是重新建设一套系统，而是在一期架构之上增加“操作型能力”。

## 3. 二期扩展内容

### 3.1 接入层扩展

- 在现有前端对话入口上继续复用 [SmartAnalysis.vue](/D:/dxl/szkj/src/components/map/SmartAnalysis.vue:339)
- 接入 Cesium/OpenLayers 页面控制入口
- 增加网页控制入口和动作反馈展示

### 3.2 API 中台扩展

在一期知识接口基础上，新增：

- `/api/map-agent/chat`
- `/api/page-agent/chat`
- `/api/action-stream`
- `/api/action-log`

其中：

- `map-agent` 负责知识与地图混合任务
- `page-agent` 负责网页元素级操作
- `action-stream` 负责流式返回动作
- `action-log` 负责操作日志与审计

### 3.3 调度层扩展

OpenClaw 在二期新增编排能力：

- 空间意图识别
- 空间参数抽取
- 网页操作编排
- 多步骤任务链
- 知识 + 操作混合任务

### 3.4 工具层扩展

一期已有知识和文档工具，二期继续增加：

- 空间工具集
- 地理编码工具
- 网页控制工具
- 动作输出工具

## 4. 二期数据流

```text
用户一句话
  -> SmartAnalysis
  -> Node.js API中台
  -> OpenClaw Agent 判断任务类型

如果是知识问答
  -> 调 RAGFlow + 本地模型
  -> 返回回答 + 引用

如果是地图控制
  -> 调空间工具 / 地理编码
  -> 返回标准 map action
  -> 前端执行定位 / 渲染 / 高亮 / 弹窗

如果是混合任务
  -> 先检索政策
  -> 再执行地图动作
  -> 再生成模板或文档
  -> 最后归档
```

## 5. 二期对一期的复用关系

### 5.1 直接复用

- 一期 Node.js API 中台
- 一期 OpenClaw 编排框架
- 一期 RAGFlow 三套知识库
- 一期本地模型
- 一期 Obsidian / MinIO / PostgreSQL
- 一期增强解析链：规则解析 + OCR + AI 辅助抽取

### 5.2 增量扩展

- 增加空间工具和网页工具
- 增加平台接口文档与操作规则知识
- 增加动作日志、上下文记录、缓存

### 5.3 不推翻重建

二期不推翻一期知识架构，只在一期基础上新增操作层能力。因此一期的接口协议、会话管理、文档归档与知识底座都应提前保持可扩展。

## 6. 二期核心能力清单

- 自然语言定位地图区域
- 自然语言高亮地图结果
- 自然语言渲染 GeoJSON
- 自然语言控制网页元素
- 自然语言混合执行“查政策 + 控地图 + 生成文档”
- 动作回放、日志、审计

## 7. 二期实施建议顺序

1. 扩展 API 中台，增加动作类接口
2. 建立统一 map action / page action 协议
3. 建立空间工具集与地理编码工具
4. 接入网页控制工具
5. 把平台接口文档和地图规则文档纳入知识库
6. 建立知识与操作混合任务链
7. 增加操作日志、回放和审计

## 8. 二期验收标准

- 用户可通过自然语言触发地图定位或高亮
- 用户可通过自然语言控制网页部分功能
- 系统能把知识问答与地图动作串联起来
- 所有关键动作具备日志记录和可追踪性
- 二期扩展不影响一期知识问答能力的稳定运行

## 9. 二期完成后的状态

二期完成后，系统将从“知识型 AI 工作台”升级为“知识 + 操作型 AI 工作台”，不仅能回答政策问题，还能把知识转化为地图动作、网页动作和文档产出动作。
