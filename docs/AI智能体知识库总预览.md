# AI智能体知识库总预览

## 1. 建设目标

本项目计划分两阶段建设一套面向规划、自然资源、测绘、巡检、用地、招投标、工程报批等场景的 AI 智能体知识库系统。

第一阶段先建设企业工程政策知识库系统，作为当前前端 AI 对话窗口的后端大脑，优先提供：

- 政策问答
- 原文追溯
- 依据比对
- 资料归档
- 模板生成
- 工程文档复刻

第二阶段在第一阶段稳定运行的基础上，再扩展自然语言控制前端网页与地图页面的能力。

## 2. 当前架构原则

- 保留现有 Vue 前端结构
- 不改现有旧后端业务接口
- 新增 Node.js API 中台承接 AI 与知识库能力
- 使用 RAGFlow 作为知识库核心引擎
- 使用局域网 Ollama 模型组合做解析、问答、OCR 和后续推理

## 3. 一期新增需求已纳入总蓝图

第一阶段新增并已经落实到方案中的关键需求有：

### 3.1 文档解析必须升级为增强解析链

解析链不再是单纯“HTML / PDF / DOCX 文本提取”，而是统一升级为：

```text
原始文件
  -> 文件类型识别
  -> 规则解析
  -> OCR 提取
  -> AI 结构化抽取
  -> Markdown 标准化
  -> 审核入库
```

### 3.2 一期必须考虑图片与扫描件

因为政策文档中存在：

- 扫描版 PDF
- 图片型附件
- 公文截图
- 表格截图
- 带盖章页

所以 OCR 已被明确纳入一期，不再视为后续优化项。

### 3.3 本地模型组合分工明确

当前已有 4 个本地模型，已明确分工：

- 基础问答：`qwen2.5:32b-instruct-q4_K_M`
- 结构化抽取：`qwen2.5:32b-instruct-q4_K_M`
- 复杂推理预留：`qwen3.6:35b-a3b-q4_K_M`
- 视觉 / OCR：`qwen2.5vl:7b`
- Embedding：`bge-m3:latest`

- 局域网 Ollama 接入
- 模型角色化配置
- 政策来源配置
- 采集任务基础链路
- HTML 规则解析
- OCR 层接口
- AI 结构化抽取
- 审核入库基础版流转
- RAGFlow 三套知识库真实创建
- approved 文档到 RAGFlow 的基础同步链
- T6 烟测脚本

补充说明：

- 当前 `T7` 已完成基础入库版
- 已能把解析结果推进到待审核，再审批为正式文档
- 但审核台前端、RAGFlow 同步、批量审核和更强去重仍属于后续增强项

### 5.2 当前还未完全做到

- PDF 真实解析器
- DOCX 真实解析器
- 图片 OCR 的真实样本验收
- 编码修复策略继续增强
- 列表页抽取按站点规则精细化
- 审核入库企业化细节完善
- RAGFlow 同步链企业化增强
- 带引用的正式知识问答

## 6. 后续重点

当前第一阶段最重要的下一步是：

- `M2 / T7` 审核入库

原因是当前系统已经具备：

- 能抓
- 能解析
- 能 OCR / AI 抽取

现在需要把这些结果变成：

- 可审核
- 可去重
- 可正式入库
- 可同步到知识库
